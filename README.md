# 挖空背书小程序

一个帮助背诵的微信小程序：粘贴文本 → 荧光笔标注重点 → 背书模式自动挖空，按住下划线查看原文，松开继续回忆。

基于微信原生小程序 + 云开发（云函数 + 云数据库），无第三方前端依赖，导入即可运行。

## ✨ 功能特性

- **笔记管理**：新建、删除笔记，列表按创建时间倒序展示
- **文本编辑**：标题 + 正文编辑，字号 24–64 rpx 可调并记住偏好，行高随字号联动
- **荧光笔标注**：手指 / 触控笔涂抹高亮重点，5 种荧光色，支持擦除、撤销、轻点删除
- **背书挖空**：标注每次随机分为 3 组轮流挖空（均分，余数优先给第 1 组），按住下划线瞬间显示原文，松开恢复
- **标注锚定**：正文修改后标注按文字自动重定位，被改动的标注自动失效并提示，不会错位
- **多设备编辑锁**：30 秒心跳 + 3 分钟超时，防止两台设备同时编辑同一篇笔记
- **离线可用**：本地缓存兜底，断网可继续编辑与背书，联网后自动同步云端
- **安全设计**：所有数据读写都经由云函数，openid 由服务端上下文注入，客户端无法伪造身份访问他人数据

## 🚀 快速开始

### 前置要求

- 微信开发者工具（建议最新稳定版）
- 微信小程序账号（个人主体即可）
- 基础库 2.2.3 及以上

### 运行步骤

1. **导入项目**：克隆 / 下载代码后，用微信开发者工具打开项目根目录。
2. **修改 AppID**：在开发者工具中把 `project.config.json` 里的 `appid` 改为你自己的小程序 AppID。
3. **开通云开发**：工具栏点击「云开发」，开通一个云环境。
4. **创建集合**：云开发控制台 → 数据库 → 新建集合 `notes`。
5. **部署云函数**：编辑器里右键 `cloudfunctions/notes` →「上传并部署：云端安装依赖」。
6. **配置环境 ID（可选）**：如有多个云环境，把 [miniprogram/app.js](miniprogram/app.js) 中 `wx.cloud.init` 的 `env` 填上环境 ID；只有一个环境时留空即可。
7. 编译运行。

## 🗄️ 数据模型

`notes` 集合：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `_id` | string | 自动生成 |
| `openid` | string | 所属用户（云函数服务端注入） |
| `title` | string | 笔记标题 |
| `content` | string | 原文文本（保留 `\n` 换行） |
| `createTime` / `updateTime` | date | 创建 / 更新时间 |
| `editingOpenid` | string | 编辑锁持有者 openid，空串表示未锁定 |
| `editingTimestamp` | number | 编辑锁心跳时间戳，3 分钟无心跳自动失效 |
| `annotations` | array | 荧光标注数组：`{aid, startIdx, endIdx, text, color}` |

## ☁️ 云函数 API

`notes` 云函数按 `type` 字段分发，小程序端通过 `wx.cloud.callFunction` 调用：

| type | 说明 |
| --- | --- |
| `getNoteList` | 查询当前用户全部笔记（按创建时间倒序） |
| `getNoteById` | 查询单条笔记（进入编辑页前校验编辑锁） |
| `createNote` | 新建笔记 |
| `updateNote` | 更新标题 / 正文 / 标注 |
| `deleteNote` | 删除笔记 |
| `updateLock` / `releaseLock` | 编辑锁心跳 / 释放 |
| `getOpenid` | 获取当前用户 openid |

所有数据库访问都经由云函数（服务端权限），客户端无法直接读写数据库。

## ❓ 常见问题

- **报错 `-601034`（没有权限）**：未开通云开发或 `env` 填错，按上文步骤 3、6 检查。
- **提示「notes 集合不存在」**：云开发控制台中还没有创建 `notes` 集合。
- **显示离线模式**：断网时自动使用本地缓存，联网后自动同步，无需手动操作。
